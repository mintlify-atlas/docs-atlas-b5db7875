## Overview

Chronos-DFIR is a comprehensive forensic timeline explorer and Digital Forensics & Incident Response (DFIR) analysis platform. It ingests multi-format evidence from various sources, applies advanced threat detection using Sigma and YARA rules, and renders interactive timelines with risk-scored intelligence.

## Architecture

Built with a modern, high-performance stack:

- **Backend**: Python 3.12+ with FastAPI and uvicorn
- **Data Engine**: Polars vectorized processing with PyArrow
- **Frontend**: Tabulator.js with virtual DOM and Chart.js visualization
- **Detection**: Sigma YAML and YARA rules with offline-first processing
